Privacy Policy

This policy applies to the Agent Hotwire application and to this website. Operator: Agent Hotwire, contact gta6agenthotwire@gmail.com.

1. This website

This website is a static page. We do not use cookies, analytics, advertising or tracking, and we do not collect personal data from visitors. The web host may process technical data such as the IP address in server logs to deliver the page.

2. The application and the accounts it connects to

The application connects only to accounts that the operator owns: the YouTube channel, the Instagram account and the Facebook Page of Agent Hotwire, and the TikTok account of Agent Hotwire. Access is granted by the operator through the official sign-in of each platform (OAuth / system user token).

The application uses this access to: upload and publish our own videos and their titles and descriptions; read the publication status and basic performance figures (such as views) of our own videos; and, if the operator switches it on, read and reply to comments on our own videos.

3. What we store

  • Access tokens, kept in a protected file on the operator’s own computer. They are never published or shared.
  • Records of our own publications (video IDs, status, performance figures).
  • If comment handling is enabled: the public text and author name of comments on our own videos, to answer them. Such data is not sold, not used for advertising and not shared with third parties other than the platform it came from.

4. Third-party services

To create content the application sends non-personal text (research topics and scripts) to AI and speech services (OpenAI, ElevenLabs). No personal data of viewers is sent to these services.

5. Google API Services – Limited Use

The application’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through the YouTube API is used only to upload and manage the operator’s own videos and channel, and is not transferred to others or used for advertising.

6. Revoking access and deletion

The operator can revoke access at any time in the security settings of Google, Meta and TikTok. Stored data can be deleted at any time. To ask about data concerning you, write to gta6agenthotwire@gmail.com; we will answer within 30 days.

7. Changes

We may update this policy; the date at the bottom of the page shows the latest version.
